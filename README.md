​🌐 URLHub
​URLHub — це сучасний, швидкий та зручний інструмент для керування, скорочення та організації вашими посиланнями в одному місці.
![_20261015_161335.JPG](https://github.com/user-attachments/assets/e8e4d6a7-59de-4d76-afa0-97d854e2fd3b)



​🚀 Основні можливості
​🔗 Скорочення посилань: Перетворюйте довгі URL на короткі та зручні для поширення посилання.
​📁 Зручна організація: Групуйте посилання за тегами, категоріями або проєктами.
​📊 Аналітика та статистика: Відстежуйте кількість переходів, географію користувачів та активність.
![IMG_20261015_161409.jpg](https://github.com/user-attachments/assets/fd5c664c-f301-420a-b8bd-861a0269c375)



​🔒 Безпека та контроль: Захист посилань паролем або налаштування терміну дії (expiration date).
​⚡ Висока продуктивність: Швидка робота завдяки сучасній архітектурі.
​🎨 Сучасний інтерфейс: Інтуїтивно зрозумілий UI/UX дизайн із підтримкою темної теми.

​🛠 Технології
​Проєкт розроблений із використанням сучасного стека технологій:
​Frontend: HTML5, CSS3, JavaScript / TypeScript / React (або інший фреймворк)
​Backend: Node.js / Python / Go
​База даних: MongoDB / PostgreSQL / Redis
​Контейнеризація: Docker & Docker Compose
​
 Швидкий старт (Встановлення)
​Щоб запустити проєкт локально, виконайте наступні кроки: 
```
# 1. Клонуйте репозиторій
git clone https://github.com/Fapbeta/URLHub.git

# 2. Перейдіть до директорії проєкту
cd URLHub

# 3. Встановіть залежності
npm install  # або pip install -r requirements.txt

# 4. Налаштуйте змінні середовища (створіть файл .env)
cp .env.example .env

# 5. Запустіть додаток
npm run dev

```
